# SOFTWARE REQUIREMENTS SPECIFICATION (SRS)

## 1. Introduction
IRO (Issues Reporting Outlet) is a web-based system developed to allow AAUA students and indigenes to report problems affecting their community.

## 2. Purpose
The purpose of IRO is to provide a simple and accessible platform for reporting community issues.

## 3. Users
- Students
- Indigenes
- System administrator

## 4. Functional Requirements
- Users can enter their name.
- Users can select an issue category.
- Users can provide the location of the issue.
- Users can describe the problem.
- Users can submit an issue report.
- The system displays a submission confirmation.

## 5. Non-Functional Requirements
- The system should be easy to use.
- The system should respond quickly.
- The interface should be simple and clear.
- The system should be accessible through a web browser.

## 6. System Requirements
The system requires a web browser and an internet-enabled device.

## 7. Conclusion
IRO provides a simple platform for reporting issues and can help improve communication between community members and relevant authorities.
