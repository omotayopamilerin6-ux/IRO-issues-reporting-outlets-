# IRO - Issues Reporting Outlet

## Project Description
IRO (Issues Reporting Outlet) is a web-based system designed to help students and indigenes report issues affecting their community.

## Main Purpose
The system provides a simple platform where users can submit information about problems such as electricity, water supply, roads, security and internet services.

## Features
- Issue reporting form
- Issue category selection
- Location of the issue
- Description of the problem
- Successful submission message
