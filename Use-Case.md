# IRO - USE CASE DOCUMENT

## System
Issues Reporting Outlet (IRO)

## Actors
1. Student
2. Indigene
3. Administrator

## Use Case 1: Report an Issue
The user enters their name, selects the issue category, enters the location, describes the problem, and submits the report.

## Use Case 2: Select Issue Category
The user selects the type of problem, such as electricity, water, road, security, or internet.

## Use Case 3: Provide Issue Location
The user enters the location where the problem occurred.

## Use Case 4: Submit Report
The user submits the completed report and receives a confirmation message.

## Use Case 5: Manage Reports
The administrator reviews reported issues and can use the information to follow up on reported problems.

## Expected Outcome
The system provides a simple way for students and indigenes to report community issues.
